# fork bleachack

A fork of [bleachack]([https://github.com/bleachack](https://github.com/BleachDev/BleachHack)) — a Minecraft utility mod ported to **1.21.11**.

## About

This repository is a fork of the original `bleachack` project, updated to work with Minecraft **1.21.11**. It aims to preserve the original feature set while keeping compatibility with the latest game version.

## Features

- Ported to Minecraft 1.21.11
- Based on the original bleachack codebase
- Utility modules and client features from upstream
- Actively maintained fork (bug fixes & compatibility updates)

## Requirements

- **Minecraft:** 1.21.11
- **Java:** 21+
- **Fabric Loader** (or the loader used by the upstream project — adjust as needed)
- **Fabric API**

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for Minecraft 1.21.11.
2. Download the latest release from the [Releases](../../releases) page.
3. Place the `.jar` file into your `mods` folder.
4. Launch the game with the Fabric profile.

## Building from source

```bash
git clone https://github.com/Legonin-dev/BleachHack-1.21.11
cd BleachHack-1.21.11
./gradlew build
```
The built jar will be located in build/libs/.
## Usage
Default keybind Right Shift.
Configure modules via the in-game GUI.
